Google Login — Token Tester untuk Postman

⚠️ Sebelum klik Sign-In: Pastikan URL ini sudah didaftarkan di Google Cloud Console

Buka Google Cloud Console → Credentials → OAuth 2.0 Client ID kamu →
Bagian "Authorized redirect URIs" → klik + ADD URI → paste URL di bawah ini:

{{ callback_url }}

Setelah Save di Google Cloud Console, tunggu 1–2 menit lalu refresh halaman ini.

Cara pakai:
1. Pastikan URL di atas sudah didaftarkan di Google Cloud Console
2. Klik tombol Sign in with Google di bawah
3. Pilih akun Google — halaman akan redirect ke Google lalu kembali
4. Token otomatis tampil → klik 📋 Copy Token → paste ke Postman di field id_token
⚠️ Error:
Klik tombol untuk Sign in dengan Google

✅ Cara test di Postman setelah dapat token

Method & URL:

POST http://127.0.0.1:8000/api/auth/google-login/

Header:

Content-Type: application/json

Body (raw → JSON):

{ "id_token": "PASTE_TOKEN_DI_SINI" }
Dicopy! 🎉
